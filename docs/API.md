# API Documentation — «Адаптация студентов» (MVP)

## Базовые сведения
- **Базовый URL**: `http://localhost:8080` (порт по умолчанию)
- **Формат данных**: JSON
- **Кодировка**: UTF-8
- **Версия**: 1.0

Все ответы с ошибками имеют единую структуру:
```json
{
  "error": "Сообщение об ошибке"
}
```

Соответствие HTTP-статусов:
- `200` — успешный GET или PATCH
- `201` — успешное создание (POST)
- `400` — ошибка валидации или некорректный запрос
- `404` — ресурс не найден
- `500` — внутренняя ошибка сервера

---

## Эндпоинты

### 1. Группы

#### 1.1 Создать группу
**POST** `/groups`

**Тело запроса**:
```json
{
  "name": "Группа 101"
}
```
Поле `name` — обязательно, строка, не пустая.

**Ответ** (201 Created):
```json
{
  "id": 1,
  "name": "Группа 101"
}
```

**Ошибки**:
- `400` — если `name` отсутствует или пустое.
- `500` — ошибка БД.

---

#### 1.2 Получить список групп
**GET** `/groups`

**Ответ** (200 OK):
```json
[
  {
    "id": 1,
    "name": "Группа 101"
  },
  {
    "id": 2,
    "name": "Группа 102"
  }
]
```

---

### 2. Студенты

#### 2.1 Создать студента (с дефолтными задачами)
**POST** `/students`

**Тело запроса**:
```json
{
  "first_name": "Иван",
  "last_name": "Петров",
  "group_id": 1
}
```
Все поля обязательны, `group_id` должен ссылаться на существующую группу.

**Действие под капотом**:
- В одной транзакции создаётся запись студента и две задачи:
  - `Связаться с куратором`
  - `Пройти профессиональное тестирование`
- Обе задачи имеют статус `todo`.
- Если любой из шагов не удаётся, вся транзакция откатывается, студент не сохраняется.

**Ответ** (201 Created):
```json
{
  "id": 10,
  "first_name": "Иван",
  "last_name": "Петров",
  "group_id": 1,
  "created_at": "2026-06-23T10:30:00Z"
}
```

**Ошибки**:
- `400` — валидация полей (отсутствуют, пустые) или `group_id` не число.
- `404` — указанная группа не найдена.
- `500` — ошибка БД или сбой транзакции.

---

#### 2.2 Получить список студентов (с фильтром по группе)
**GET** `/students`

**Параметры запроса (query)**:
- `group_id` (обязательный) — идентификатор группы, только студенты этой группы будут возвращены.

Пример: `GET /students?group_id=1`

**Ответ** (200 OK):
```json
[
  {
    "id": 10,
    "first_name": "Иван",
    "last_name": "Петров",
    "group_id": 1,
    "created_at": "2026-06-23T10:30:00Z"
  },
  {
    "id": 11,
    "first_name": "Мария",
    "last_name": "Сидорова",
    "group_id": 1,
    "created_at": "2026-06-23T10:35:00Z"
  }
]
```

**Ошибки**:
- `400` — если параметр `group_id` не передан или не является целым числом.
- `500` — ошибка БД.

---

#### 2.3 Получить задачи конкретного студента
**GET** `/students/{id}/tasks`

Где `{id}` — идентификатор студента.

**Ответ** (200 OK):
```json
[
  {
    "id": 100,
    "student_id": 10,
    "title": "Связаться с куратором",
    "status": "todo",
    "created_at": "2026-06-23T10:30:00Z"
  },
  {
    "id": 101,
    "student_id": 10,
    "title": "Пройти профессиональное тестирование",
    "status": "todo",
    "created_at": "2026-06-23T10:30:00Z"
  }
]
```

**Ошибки**:
- `404` — студент с указанным ID не найден.
- `500` — ошибка БД.

---

### 3. Задачи

#### 3.1 Обновить статус задачи
**PATCH** `/tasks/{id}`

Где `{id}` — идентификатор задачи.

**Тело запроса**:
```json
{
  "status": "in_progress"
}
```
Допустимые значения статуса (строго):
- `todo`
- `in_progress`
- `done`

**Ответ** (200 OK):
```json
{
  "id": 100,
  "student_id": 10,
  "title": "Связаться с куратором",
  "status": "in_progress",
  "created_at": "2026-06-23T10:30:00Z"
}
```

**Ошибки**:
- `400` — статус отсутствует или имеет недопустимое значение.
- `404` — задача с указанным ID не найдена.
- `500` — ошибка БД.

## Примеры cURL-запросов

### Создание группы
```bash
curl -X POST http://localhost:8080/groups -H "Content-Type: application/json" -d "{\"name\":\"Группа 101\"}"
```

### Список групп
curl http://localhost:8080/groups

### Создание студента (с дефолтными задачами)
```bash
curl -X POST http://localhost:8080/students -H "Content-Type: application/json" -d "{\"first_name\":\"Иван\",\"last_name\":\"Петров\",\"group_id\":1}"
```

### Список студентов группы
```bash
curl "http://localhost:8080/students?group_id=1"
```

### Задачи студента
```bash
curl http://localhost:8080/students/10/tasks
```

### Обновление статуса задачи
```bash
curl -X PATCH http://localhost:8080/tasks/100 -H "Content-Type: application/json" -d "{\"status\":\"in_progress\"}"
```

---

## Примечания для фронтенд-разработчика
- Все даты возвращаются в формате ISO 8601 (RFC 3339) с часовым поясом (например, `2026-06-23T10:30:00Z`).
- При создании студента задачи создаются автоматически, отдельно их добавлять не нужно.
- Для фильтрации студентов всегда используйте `group_id` — он обязателен.
- В ответах на GET-списки данные отсортированы по `id` (порядок может меняться, но это несущественно).

  "error": "student not found"
